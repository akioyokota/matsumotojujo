# ホテル 年間業務ルーティン

ホテルで働くうえでの、**1日の業務ルーティン**（毎日行うこと）と、**季節・月ごとの業務**（時期によって発生すること）をまとめた記録用マニュアルです。年間を通して「いつ・何をするか」を見渡せるようにすることを目的としています。

## 1. 毎日のルーティン

時間帯にかかわらず、**毎日必ず行う**基本業務です。天候や季節に関係なく、原則として毎日実施します。

### 朝の業務

| 業務                | 内容                                             | 備考                 |
| ----------------- | ---------------------------------------------- | ------------------ |
| **入口周辺の植物への水やり**  | ホテル入口まわりの植物（鉢植え・植栽）に水をやる                       | 気温が上がる前の**午前中**が基本 |
| **入口・エントランスの清掃**  | 掃き掃除、ゴミ・落ち葉の除去、玄関まわりの整え                        | （要記入）              |
| **開店・開館準備**        | 照明・空調・BGMなど、お客様をお迎えする準備                        | （要記入）              |

**入口周辺の植物への水やりのポイント**

- **朝のうち**（気温が上がる前）に行う。日中の暑い時間帯の水やりは根を傷めやすいため避ける
- 土の表面が乾いているかを確認してから与える（毎日でも、雨天の翌日など十分に湿っている場合は控える）
- 夏場（盛夏）は乾きやすいため、朝だけでなく**夕方にもう一度**必要になることがある
- 対象の植物・鉢の位置：（要記入）

### 日中の業務

| 業務          | 内容                              | 備考    |
| ----------- | ------------------------------- | ----- |
| **館内清掃・巡回** | 共用部の清掃、客室対応、備品補充など              | （要記入） |
| **接客・お客様対応** | お出迎え・ご案内・お問い合わせ対応               | （要記入） |

### 夕方・閉館の業務

| 業務          | 内容                              | 備考          |
| ----------- | ------------------------------- | ----------- |
| **植物の水やり（夏場）** | 盛夏など乾きやすい時期は、夕方にも入口周辺の植物へ水をやる    | 朝に加えて実施     |
| **閉店・閉館作業**  | 照明・空調の調整、施錠、翌日の準備               | （要記入）       |

## 2. 季節・月ごとの業務

暖かくなる時期（**おおむね5月頃**）から始まる屋外まわりの業務など、**時期によって発生する業務**をまとめます。開始・終了の時期はあくまで目安で、天候や予約状況によって前後します。

### 年間カレンダー（概要）

| 時期            | 主な季節業務                                     |
| ------------- | ------------------------------------------ |
| 春（3〜4月）       | 屋外まわりの準備開始（芝・植栽の手入れなど）                     |
| **初夏（5月頃〜）**  | **芝・グリル・コーヒー・駐車場の送迎**（下記「5月頃からの屋外業務」を参照）    |
| 夏（6〜8月）       | 屋外業務の本格運用、水やりの頻度アップ（朝夕）                    |
| 秋（9〜11月）      | 屋外業務の縮小・片付け                                |
| 冬（12〜2月）      | 屋外業務の休止、冬季対応（要記入）                          |

### 5月頃からの屋外業務

暖かくなる**5月頃**から、次の屋外まわりの業務が始まります。

| 業務            | 内容                                            | 時期の目安       |
| ------------- | --------------------------------------------- | ----------- |
| **芝**         | 芝生エリアの整備・開放（芝刈り、養生の解除など）                      | 5月頃〜        |
| **グリル**       | 屋外グリル（バーベキュー）の設置・提供の開始と、使用後の片付け・清掃            | 5月頃〜        |
| **コーヒー**      | 屋外・テラスでのコーヒーの提供                               | 5月頃〜        |
| **駐車場の送迎（往復）** | 駐車場とホテルの間で、お客様の送迎（往復）を行う                      | 5月頃〜        |

**各業務のメモ**

- **芝**：芝刈りの頻度・使用する機材・置き場所は（要記入）
- **グリル**：設置場所、点火・消火の手順、使用後の清掃方法は（要記入）
- **コーヒー**：提供場所・時間帯・使用する器具は（要記入）
- **駐車場の送迎**：送迎に使う車両、駐車場の場所、対応する時間帯・タイミングは（要記入）
