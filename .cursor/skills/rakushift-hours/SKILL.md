# らくしふ実働時間計算スキル

らくしふのシフト表（画面コピー・貼り付けテキスト・CSV・スクリーンショット）から、各スタッフの実働時間を計算し、入力用フォーマットで返す。

## いつ使うか

- ユーザーがらくしふのシフトデータを渡し、「実働を出して」「時間を計算して」「入力用にまとめて」などと依頼したとき
- 週次・月次の労働時間集計や、勤怠／人件費入力の下書きが必要なとき

## 入力の受け方

次のいずれでも受け取る。欠けている項目は推測せず、計算に必要な不足だけ短く確認する。

1. **貼り付けテキスト**（シフト表からコピーした行）
2. **CSV**（らくしふのエクスポート、またはスプレッドシート経由）
3. **スクリーンショット／画像**（読める範囲で時刻・氏名・休憩を起こす。読めない箇所は「要確認」とする）

1行（1シフト）につき、原則次を揃える。

| 項目 | 必須 | 例 |
|------|------|-----|
| 氏名 | 必須 | 横田秋雄 |
| 日付 | あるとよい | 2026/10/12・10/12・10月12日 |
| 開始 | 必須 | 9:00 / 09:00 |
| 終了 | 必須 | 18:00 |
| 休憩 | 任意 | 60分 / 1:00 / 休憩なし |
| 店舗・ポジション | 任意 | 清掃 / ロビー |

休み・公休・希望休のみの行は実働 0 とし、集計対象外でも一覧には「休み」と残してよい。

## 計算ルール

### 基本式

```
拘束時間（分） = 終了 − 開始（日跨ぎは終了に +24時間）
実働時間（分） = 拘束時間 − 休憩時間
```

- 実働が負になる場合は計算ミスとして「要確認」にする（無理に 0 にしない）。
- 分は整数で扱い、表示時に丸める（後述）。

### 休憩の決め方（優先順）

1. **シフトに休憩が明示されている** → その値を使う（分・`H:MM`・「休憩なし」いずれも可）
2. **ユーザーが今回の依頼で休憩ルールを指定した** → そのルールを全員に適用
3. **どちらもない** → 次の**仮ルール**を使い、出力冒頭に「仮の休憩ルールで計算」と明記する

仮ルール（労働基準法の最低休憩を目安にしたデフォルト。現場ルールが分かったら上書きする）:

| 拘束時間 | 休憩 |
|----------|------|
| 6時間以下 | 0分 |
| 6時間超〜8時間以下 | 45分 |
| 8時間超 | 60分 |

現場で「常に60分」「パターン名ごとに固定」などが分かったら、スキル利用者の指示を優先し、この仮ルールは使わない。

### 表示形式

- **既定**: 小数時間（Excel 入力向け）。例：`7.5`（7時間30分）
- 分は 0.25 刻みに丸めない。`実働分 ÷ 60` を小数第2位まで（四捨五入）で出す。例：7時間20分 → `7.33`
- 併記で `H:MM`（例：`7:20`）も出すと貼り付け先を選びやすい
- ユーザーが「分だけ」「時間:分だけ」と指定したらそれに合わせる

## 出力フォーマット

**プレーンテキスト**（Markdown の表記・太字は使わない）。コピーしてスプレッドシートやチャットに貼れる形。

### 1. 冒頭メタ

```
【実働時間 松本十帖 YYYY年M月D日〜M月D日】
休憩：明示値優先 / 仮ルール（6超45分・8超60分）※現場ルールがあれば差し替え
単位：小数時間（および H:MM）
```

対象期間が1日なら日付を1つだけ書く。作成日ではなく**シフト対象期間**を書く。

### 2. 明細（入力用・タブ区切り）

先頭行はヘッダー固定。列はタブ区切り（スプレッドシートへそのまま貼れる）。

```
日付	氏名	開始	終了	休憩(分)	実働(h)	実働(H:MM)
2026/10/12	横田秋雄	9:00	18:00	60	8.00	8:00
2026/10/13	横田秋雄	8:00	17:00	60	8.00	8:00
```

- 日付は `YYYY/M/D`（先頭ゼロなしで可）
- 開始・終了は `H:MM`（例：`9:00`）
- 休みの行は実働を空欄または `休み` とし、休憩・開始終了が無ければ空欄

### 3. 氏名別合計

明細の後に空行を1つ置き、氏名ごとの合計を出す。

```
■氏名別合計
氏名	日数	実働合計(h)	実働合計(H:MM)
横田秋雄	2	16.00	16:00
```

### 4. 全体合計（任意だが原則付ける）

```
■全体
出勤延べ人数（シフト数）: N
実働合計(h): X.XX
```

## 手順（エージェント向け）

1. 入力を行単位に分解し、氏名・開始・終了・休憩・日付を抽出する。
2. 休憩ルールを確定する（明示 → ユーザー指定 → 仮ルール＋注記）。
3. 各行の実働を計算する。読めない・矛盾する行は数値を捏造せず「要確認」と書く。
4. 上記フォーマットで明細 → 氏名別合計 → 全体を出力する。
5. 仮ルールや要確認がある場合は、出力の直後に確認ポイントを2〜3行で添える。

## 入力例と出力例

### 入力例

```
10/12 横田 9:00-18:00 休憩60
10/12 佐藤 8:00-12:00
10/13 横田 9:00-15:30 休憩45
```

### 出力例

```
【実働時間 松本十帖 2026年10月12日〜10月13日】
休憩：明示値優先 / 未記載は仮ルール（6超45分・8超60分）
単位：小数時間（および H:MM）

日付	氏名	開始	終了	休憩(分)	実働(h)	実働(H:MM)
2026/10/12	横田	9:00	18:00	60	8.00	8:00
2026/10/12	佐藤	8:00	12:00	0	4.00	4:00
2026/10/13	横田	9:00	15:30	45	6.00	6:00

■氏名別合計
氏名	日数	実働合計(h)	実働合計(H:MM)
横田	2	14.00	14:00
佐藤	1	4.00	4:00

■全体
出勤延べ人数（シフト数）: 3
実働合計(h): 18.00
```

## 注意点

- **計画シフトの実働**であり、打刻実績（勤怠）とは別物。ユーザーが「実績」と言っている場合は、打刻データの有無を確認する。
- らくしふ上の「勤務パターン名」だけしか無い行は、パターン→時刻の対応表が無いと計算できない。対応が無ければ確認する。
- 深夜・日跨ぎ（例：22:00–6:00）は終了側に +24時間してから計算する。
- 個人情報の取り扱い：チャット外への転記や外部サービス送信はユーザー指示があるときだけ行う。
- 出力は計算結果そのもの。給与額・残業割増の法的判断までは行わない（求められたら別途・前提を明示）。

## 初回・ルール未確定時

現場の休憩ルールや貼り付け先（列順）がまだ分かっていないときは、このスキルの仮ルールと既定列で一度出し、ユーザーに次だけ確認する。

1. 休憩はシフト記載どおりか、全員固定か（何分か）
2. 貼り付け先で欲しい列（氏名×日付のマトリクス、小数時間のみ、など）
